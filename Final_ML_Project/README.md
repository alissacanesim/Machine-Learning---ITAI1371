# Final Machine Learning Project
## ITAI 1371 – Machine Learning

### Project Objective
This project focuses on a binary classification problem using the HR Analytics: Job Change of Data Scientists dataset from Kaggle.

The goal is to predict whether a candidate is likely to look for a job change based on demographic, educational, and professional information.

### Models Implemented
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting Classifier
- K-Nearest Neighbors Classifier
- Support Vector Classifier (SVC)
- Voting Ensemble
- Bayesian Ensemble

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
